## Work / Projects
01. [Agentic AI for Banking Customer Experience](projects/01_agentic_ai_banking_customer_experience) - This project builds an agentic AI-style banking support workflow that classifies customer requests, predicts the best service route, estimates priority, and generates a clear customer-facing response.
02. [Credit Risk Prediction](projects/02_credit_risk_prediction) - This project predicts credit risk using income, credit score, utilization, debt-to-income ratio, payment history, and loan amount.
03. [Customer Churn Prediction](projects/03_customer_churn_prediction) - This project predicts customer churn using tenure, monthly charges, satisfaction, support tickets, logins, and product usage.
04. [Fraud Detection in Transactions](projects/04_fraud_detection_transactions) - This project builds a fraud detection model using transaction amount, merchant risk, transaction time, foreign transaction status, location mismatch, and short-term account activity.
05. [Stock Price Feature Modeling](projects/05_stock_price_feature_modeling) - This project creates moving averages, returns, volatility, momentum, and volume-change features to predict whether the next trading day closes higher.
06. [Housing Price Prediction](projects/06_housing_price_prediction) - This project predicts housing prices using square footage, rooms, bathrooms, age, property quality, and neighborhood score.
07. [Delivery Delay Prediction](projects/07_delivery_delay_prediction) - This project predicts delivery delays using distance, carrier score, weather risk, package weight, warehouse processing time, and traffic conditions.
08. [TSA Complaints Analysis](projects/08_tsa_complaints_analysis) - This project studies TSA-style complaint data and predicts whether a complaint is likely to be escalated.
09. [Netflix Top 10 Storytelling Analysis](projects/09_netflix_top10_storytelling) - This project uses viewing weeks, rank, genre, release type, release age, and weekly views to identify titles likely to stay in the Top 10 longer.
10. [Childcare Price Analysis](projects/10_childcare_price_analysis) - This project analyzes childcare affordability using median income, infant care cost, preschool cost, employment rate, population density, and single-parent household rate.

## How to Run the Notebooks
1. Install Python 3.10 or later.
2. Install required libraries:
   ```bash
   pip install -r requirements.txt
   ```
3. Open Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
4. Run each notebook from top to bottom.
