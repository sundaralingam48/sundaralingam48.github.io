# Fraud Detection in Transactions

## Summary
This project builds a fraud detection model using transaction amount, merchant risk, transaction time, foreign transaction status, location mismatch, and short-term account activity.

## Business Problem
Fraud teams need to flag suspicious transactions quickly while reducing unnecessary manual review. This project predicts whether a transaction may be fraudulent.

## Tools and Skills
Python, Pandas, Fraud Detection, Classification, Confusion Matrix, Precision/Recall

## Files
- `04_fraud_detection_transactions.ipynb` - Complete Jupyter Notebook with data preparation, EDA, modeling, evaluation, and recommendations.
