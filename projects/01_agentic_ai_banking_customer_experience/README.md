# Agentic AI for Banking Customer Experience

## Summary
This project builds an agentic AI-style banking support workflow that classifies customer requests, predicts the best service route, estimates priority, and generates a clear customer-facing response.

## Business Problem
Banking customers submit many different requests related to cards, loans, fraud, payments, account access, and service support. This project demonstrates how an AI-assisted workflow can classify customer needs, assign priority, and route requests to the correct support path.

## Tools and Skills
Python, Pandas, Scikit-learn, Classification, AI Workflow, Banking Analytics

## Files
