# Stock Price Feature Modeling

## Summary
This project creates moving averages, returns, volatility, momentum, and volume-change features to predict whether the next trading day closes higher.

## Business Problem
Investors and analysts often use technical indicators to summarize price behavior. This project engineers technical indicators and predicts next-day stock direction.

## Tools and Skills
Python, Pandas, Time Series, Feature Engineering, Financial Analytics

## Files
- `05_stock_price_feature_modeling.ipynb` - Complete Jupyter Notebook with data preparation, EDA, modeling, evaluation, and recommendations.
