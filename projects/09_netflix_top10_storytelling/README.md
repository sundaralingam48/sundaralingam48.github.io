# Netflix Top 10 Storytelling Analysis

## Summary
This project uses viewing weeks, rank, genre, release type, release age, and weekly views to identify titles likely to stay in the Top 10 longer.

## Business Problem
Streaming platforms and content teams benefit from understanding which titles remain popular over time. This project analyzes ranking and viewing features to identify long-running titles.

## Tools and Skills
Python, Pandas, EDA, Storytelling, Classification, Visualization

## Files
- `09_netflix_top10_storytelling.ipynb` - Complete Jupyter Notebook with data preparation, EDA, modeling, evaluation, and recommendations.
