# Delivery Delay Prediction

## Summary
This project predicts delivery delays using distance, carrier score, weather risk, package weight, warehouse processing time, and traffic conditions.

## Business Problem
Logistics teams need early warnings when deliveries are at risk of delay. This project predicts delivery delay risk using shipment and operating conditions.

## Tools and Skills
Python, Pandas, Logistics Analytics, Classification, Business Recommendations

## Files
- `07_delivery_delay_prediction.ipynb` - Complete Jupyter Notebook with data preparation, EDA, modeling, evaluation, and recommendations.
