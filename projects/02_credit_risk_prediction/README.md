# Credit Risk Prediction

## Summary
This project predicts credit risk using income, credit score, utilization, debt-to-income ratio, payment history, and loan amount.

## Business Problem
Financial institutions need consistent ways to identify loan applicants who may require additional risk review. This project uses applicant and loan characteristics to predict high-risk applications.

## Tools and Skills
Python, Pandas, Scikit-learn, Logistic Regression, Random Forest, Risk Analytics

## Files
- `02_credit_risk_prediction.ipynb` - Complete Jupyter Notebook with data preparation, EDA, modeling, evaluation, and recommendations.
