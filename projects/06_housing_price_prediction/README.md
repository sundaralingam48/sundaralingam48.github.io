# Housing Price Prediction

## Summary
This project predicts housing prices using square footage, rooms, bathrooms, age, property quality, and neighborhood score.

## Business Problem
Home buyers, sellers, and analysts need practical ways to estimate property value. This project predicts sale price using property characteristics.

## Tools and Skills
Python, Pandas, Regression, Random Forest, RMSE, Real Estate Analytics

## Files
- `06_housing_price_prediction.ipynb` - Complete Jupyter Notebook with data preparation, EDA, modeling, evaluation, and recommendations.

## Repository / Portfolio Link
https://github.com/sundaralingam48/house-price-prediction-ml

## Notes
This notebook is self-contained and uses simulated data so it can run successfully for portfolio review. The workflow can be adapted to a real dataset.
