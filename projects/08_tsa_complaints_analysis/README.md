# TSA Complaints Analysis

## Summary
This project studies TSA-style complaint data and predicts whether a complaint is likely to be escalated.

## Business Problem
Public agencies can improve service by understanding complaint patterns. This project analyzes complaint escalation risk using airport, category, volume, and response-time features.

## Tools and Skills
Python, Pandas, Public Data, Classification, Data Storytelling

## Files
- `08_tsa_complaints_analysis.ipynb` - Complete Jupyter Notebook with data preparation, EDA, modeling, evaluation, and recommendations.
