# Childcare Price Analysis

## Summary
This project analyzes childcare affordability using median income, infant care cost, preschool cost, employment rate, population density, and single-parent household rate.

## Business Problem
Childcare affordability is an important issue for families, employers, and policymakers. This project estimates an affordability index using cost, income, employment, and household factors.

## Tools and Skills
Python, Pandas, Regression, Social Analytics, Data Visualization

## Files
- `10_childcare_price_analysis.ipynb` - Complete Jupyter Notebook with data preparation, EDA, modeling, evaluation, and recommendations.
